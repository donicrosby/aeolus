# Aeolus
A modular window extraction fan that uses common PC fans as the extraction component

## Setup
There are a few submodules that need to be pulled in this can be done by:

```bash
git clone --recurse-submodules https://github.com/donicrosby/aeolus.git
```

Or after already cloning the repo:

```bash
git clone ttps://github.com/donicrosby/aeolus.git
git submodule update --init --recursive
```
